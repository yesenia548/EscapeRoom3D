## Objetivo
Explorar una habitación colorida, resolver un código, abrir un cofre, obtener una llave y abrir la puerta de salida.

## Cómo jugar

WASD mover · Mouse mirar · E interactuar.
1. Lee la nota amarilla de la pared oeste (pista).
2. Usa el panel verde de la pared este e ingresa el código (1234).
3. Abre el cofre, toma la llave y abre la puerta azul (pared norte).
